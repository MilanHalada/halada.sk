# Milan Halada - Developer Portfolio

A professional, responsive portfolio website built with React showcasing my experience as a full-stack developer.

## Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Modern UI**: Clean, professional design with smooth animations
- **Work Experience**: Complete timeline of professional experience
- **Featured Projects**: Detailed showcase of recent projects (SmartBooks, Beri, BlueWinston)
- **Contact Information**: Multiple ways to get in touch
- **Smooth Navigation**: Fixed header with smooth scrolling to sections

## Technologies Used

- React 18
- CSS3 with modern features (Grid, Flexbox, Gradients)
- Responsive design principles
- Smooth animations and transitions

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Clone the repository or download the files
2. Navigate to the project directory
3. Install dependencies:

```bash
npm install
```

### Running the Application

Start the development server:

```bash
npm start
```

The application will open in your browser at `http://localhost:3000`.

### Building for Production

To create a production build:

```bash
npm run build
```

The build files will be in the `build` directory.

## Sections

1. **Header**: Fixed navigation with smooth scrolling
2. **About**: Introduction with skills and professional summary
3. **Experience**: Complete work history with technologies used
4. **Featured Projects**: Detailed showcase of recent projects
5. **Contact**: Contact information and call-to-action

## Customization

To customize the portfolio:

1. Update personal information in the respective component files
2. Modify colors and styling in the CSS files
3. Add or remove projects in `FeaturedProjects.js`
4. Update work experience in `Experience.js`
